## 받기 · 설치

1. 아래 **Assets** 에서 **`Siosa-v{VERSION}.zip`** 을 받아 원하는 곳에 풉니다.
2. `Siosa.exe` 를 실행합니다. **설치가 필요 없고, 프로그램은 exe 파일 하나**입니다.

> **처음 실행할 때 "Windows의 PC 보호" 창이 뜨면** `추가 정보` → `실행` 을 누르세요.
> 인터넷에서 받은 서명 없는 프로그램에 Windows(SmartScreen)가 띄우는 안내입니다. 한 번 실행하면 다음부터는 뜨지 않습니다.

- 필요: Windows 10/11
- 처음 실행하면 exe 옆에 `SiosaData` 폴더가 생기고 설정 · 프리셋 · 진행 기록이 저장됩니다. 옮길 때는 `Siosa.exe` 와 `SiosaData` 를 같이 옮기세요.
- 게임 입력(키보드 · 마우스)을 읽거나 보내지 않습니다. 화면 일부와 게임 로그 파일만 읽습니다.

## 시작하기

1. **PoB 불러오기**(PoB 코드나 pobb.in 링크) 또는 **새로 만들기**로 프리셋을 만듭니다.
2. 아래 **시작** 을 누르면 오버레이가 뜹니다. 설정을 다시 열 때는 트레이의 Siosa 아이콘을 더블클릭하세요.
3. 게임에서 보상 NPC 와 대화해 보상 창을 열면 고른 보상이 강조됩니다.

| 단축키 (Ctrl+Shift+) | 기능 |
|---|---|
| `W` / `E` | 오버레이 옮기기 / 숨기기 |
| `L` · `J` `K` | 링크 표시 · 이전/다음 단계 |
| `P` · `U` `I` · `-` `=` | 패시브 트리 창 · 이전/다음 단계 · 크기 |
| `T` | 지역 팁 켜기/끄기 |
| `G` / `F` | 구매 젬 정규식 / 정규식 복사 (상점 검색칸에 Ctrl+V) |

자세한 사용법(화면 그림 포함): **https://github.com/nwangxyz/siosa#readme**
