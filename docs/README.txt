Siosa - Path of Exile 1 (카카오 한국 클라이언트) 액트 진행 보조 오버레이

[시작하기]
1. Siosa.exe 를 실행합니다. (설치 필요 없음, 프로그램은 이 파일 하나)
   처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 '추가 정보' → '실행'을 누르세요.
   (인터넷에서 받은 서명 없는 프로그램에 Windows 가 띄우는 안내입니다. 한 번 실행하면 다음부터는 뜨지 않습니다)
2. 새로 만들기 또는 PoB 불러오기로 프리셋을 만들고 '시작'을 누릅니다.
3. 게임에서 퀘스트 보상 창을 열면 고른 보상이 강조됩니다.
   설정을 다시 열 때는 작업 표시줄 오른쪽 트레이의 Siosa 아이콘을 더블클릭합니다.

[폴더]
- 처음 실행하면 exe 옆에 SiosaData 폴더가 생기고 설정·프리셋·진행 기록이 저장됩니다.
- 다른 곳으로 옮길 때는 Siosa.exe 와 SiosaData 폴더를 같이 옮기면 그대로 이어집니다.

[업데이트]
- 메인 화면에 새 버전이 표시되면 '업데이트' 버튼을 누르면 됩니다. SiosaData 는 그대로 남습니다.

[안내]
- 게임 입력을 읽거나 보내지 않습니다. 화면 일부와 게임 로그 파일만 읽습니다.
