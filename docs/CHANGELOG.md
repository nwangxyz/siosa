# 변경 사항

새 버전을 올릴 때 맨 위에 `## v<버전>` 항목을 추가합니다. 릴리스 페이지 본문 맨 위에 이 항목이 들어갑니다 (release.ps1).

## v1.0.0

첫 공개 버전입니다.

- 퀘스트 보상 강조: 미리 고른 보상을 보상 창에서 바로 표시 (해상도 자동 · 창 모드 지원)
- PoB 불러오기: 직업 · 보상 · 구매 젬 · 링크 · 패시브 트리를 한 번에
- 진행 오버레이: 지역 · 레벨 · 경험치 패널티 · 패시브 포인트, 마을에서 받을 보상과 살 젬
- 링크 · 패시브 트리 창 · 지역 팁
- 상점 검색 정규식: `Ctrl+Shift+G` 이 액트에서 살 젬 / `Ctrl+Shift+F` 자주 찾는 옵션
- 프리셋 = 캐릭터: 이전 진행 불러오기 · 새 캐릭터로 시작
- 포터블 exe 하나, 새 버전 자동 업데이트
